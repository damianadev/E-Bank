# DJBank

DJBank is my personal banking app pet project built with HTML, CSS and JavaScript.

The project simulates a simple banking system where users can:

* create and switch between accounts
* have their own IBAN and balance
* send DJCOINS to other users
* send money requests
* accept or decline requests
* track request statuses
* store data using LocalStorage

The main goal of the project is to practice JavaScript and build real application logic using DOM, events, objects, arrays, JSON and LocalStorage.

> Educational project. No real money or banking services are involved.
